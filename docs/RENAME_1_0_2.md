# Ready Yet? 1.0.2 brand update

Version 1.0.2 gives the app the displayed name **Ready Yet?** and keeps **Before I Leave** as its tagline. The change applies to onboarding and Settings, Android app/widget labels, launcher-widget previews and instructions, reminder notifications, native widget projections, and the current README and design plan.

This combined release also redesigns the native checklist and quick-list widgets; see [the widget design notes](WIDGET_REDESIGN_1_0_2.md). The Android application ID and namespace, Kotlin package and component names, Flutter package/internal imports, MethodChannel, private state and backup filenames, widget preference keys, reminder preferences and PendingIntent identities, JSON schema, permissions, icons, and saved user data remain unchanged. Existing 1.0.0 and 1.0.1 APKs and source archives are preserved.

Release artifact: `dist/Ready-Yet-1.0.2-arm64-v8a.apk`. See [APK verification](../qa/APK_VERIFICATION.md) for the exact build command and package, signing, architecture, resource, and compatibility checks.
